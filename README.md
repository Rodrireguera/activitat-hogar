# IOC Angular Activitat Hogar - Rodrigo Fernández

## Descripció
Aplicació web desenvolupada amb Angular per gestionar activitats i tasques de la llar. Per exemple: Lampistes, fusters, empreses de la neteja, cuidadors/es, empresa de l’ascensor, serraller. També on puguis introduir les despeses i et fagi un càlcul mensual i anual de las despeses de la llum, industrials, aigua, comunitat, industrials... 

## Stack Tècnic
- Angular CLL 18.2.21 (Standalone Architecture)
- TypeScript
- SCSS (Sass)
- Angular Router
- Node.js 20.20.0 LTS
- npm 10.8.2
